## Description of notebooks according their purposes

1. **Munsell_C_to_Lab_D65_to_Munsell_C**: This test code takes a Munsell colour code—the default value, `10B 9/2`, taken from  [Otsuka & Nakae](https://doi.org/10.3168/jds.S0022-0302(69)86894-3), who reported it for resazurin added to milk—and treats it as specified under Illuminant C, the standard illuminant for the Munsell system. It converts the code to CIE L\*a\*b\* values defined under Illuminant D65 and subsequently reconstructs the corresponding standard Munsell colour code. The notebook is intended as an auxiliary tool for verifying the self-consistency of the conversion procedures.
2. **Munsell_to_Lab_RGB**:  This program imports a `.csv` table containing two columns—an item ID and a Munsell colour code (`Item,Munsell code`). The latter is specified relative to Illuminant C, the conventional reference standard. Two modes are available: `reference`, which retrieves a table prefilled with commonly accepted literature values (LP: [Otsuka & Nakae](https://doi.org/10.3168/jds.S0022-0302(69)86894-3); L: [Golding & Jorgensen](https://www.sciencedirect.com/science/article/pii/S0362028X23038711), [Smith *et al.*](https://doi.org/10.1016/S0315-5463(77)73494-7)), or a mode in which the user uploads a completed file. The output is a `.docx` file containing a table with the input data, generated CIE L\*a\*b\* and RGB values corresponding to Illuminant D65, and illustrative colour rectangles.
3. **KubelkaMunk_ColorAnalysis**: This file implements parameter optimization for reflectance functions used to calculate a reflectance spectrum and its corresponding colour, and reports the optimized parameters. The optimization seeks to reproduce a prescribed target colour specified as a CIE L\*a\*b\* triplet under Illuminant D65. The code also reports the corresponding RGB and Munsell codes, the latter conventionally defined under Illuminant C, as well as colour images representing the target and spectrum-adjusted colours. 
4. **Resazurin_Resorufin_Color_Mixing_Reflection**: This file calculates the colours of a model white-scattering medium (milk) containing resazurin and resorufin in user-defined mixing fractions. Calculations are performed over a pH range of 1–9 in increments of 0.5, based on experimentally normalized transmission spectra of resazurin and resorufin and on the Kubelka–Munk scattering-function parameters determined using the *KubelkaMunk_ColorAnalysis* notebook.  The output is an Excel file containing CIE L\*a\*b\* and RGB values, both defined under Illuminant D65; Munsell codes, conventionally defined under Illuminant C; and illustrative colour swatches.
5. **Image_Color_Analysis**: This file allows the user to upload a set of raster digital images—supported formats are `.bmp`, `.gif`, `.jpeg`, `.jpg`, `.png`, `.tif`, `.tiff`, and `.webp`—packaged in a `.zip` archive. It generates an Excel file containing the median RGB values and the corresponding CIE L\*a\*b\* values, both defined under Illuminant D65, as well as the corresponding Munsell codes under Illuminant C. Munsell codes are reported both in extended notation with decimal values and in the rounded form typically used in older colour atlases. *Important note:* Even when processing a single image, it must be packaged in a `.zip` archive.  
6. **Color_wheel_CIE_Lab_a_b_L**: This auxiliary program plots sets of \((a^*, b^*)\) pairs on a CIE L\*a\*b\* chromaticity diagram at a fixed \(L^*\) value, which can be changed manually in the program. The input `.csv` file must contain three columns: the first for dataset IDs and the second and third for the corresponding \(a^*\) and \(b^*\) values. Points sharing the same ID are plotted as a sequence of markers with a unique style. Each ID is also used as the corresponding legend label, so descriptive labels can be provided directly in the `.csv` file.
